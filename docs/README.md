# Kanting frontend (plain HTML + CSS + JavaScript)
No React, no Node, no build step.

1. Start the Flask backend (port 5000).
2. From this folder run: python3 -m http.server 5173
3. Open http://127.0.0.1:5173
Backend URL: edit API_URL in js/api.js, or run localStorage.setItem('kanting_api','https://YOUR-NGROK-URL') in the browser console.
